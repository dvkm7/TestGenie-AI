## 4. Challenges & Mitigations
- **Challenge:** Occasional formatting inconsistencies when the model wrapped code in triple backticks inside JSON strings.  
  *Mitigation:* Leveraged Gemini's native `responseSchema` options to eliminate markdown wrapper parsing bugs.
- **Challenge:** Balancing generation latency with test case quality.  
  *Mitigation:* Tuned model selection to `gemini-3.8-flash` which delivers sub-2 second synthesis times while maintaining high Python syntax accuracy.
