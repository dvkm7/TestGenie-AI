---

## 4. Challenges & Mitigations
- **Challenge:** Infinite loops (`while True:`) in student code hanging the server.  
  *Mitigation:* Enforced 5-second hard timeout with `child_process.kill('SIGKILL')`, returning a graceful `timed_out` status with an educational diagnostic message.
- **Challenge:** Capturing user `print()` calls without breaking JSON output on `sys.stdout`.  
  *Mitigation:* Used Python `contextlib.redirect_stdout` to capture runtime output in internal `io.StringIO` buffers, leaving the main `sys.stdout` stream clean for structured JSON.
